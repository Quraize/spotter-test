# Data files

| File | Origin | Role |
|---|---|---|
| `fuel-prices-for-be-assessment.csv` | Provided with the assessment (OPIS truck stop diesel prices) | Source of stations and prices. Never edited. |
| `us_cities.csv` | Built by `manage.py build_city_table` from [GeoNames cities500](https://www.geonames.org/) (CC BY 4.0) and [kelvins/US-Cities-Database](https://github.com/kelvins/US-Cities-Database) (MIT) | Offline "City, ST" → lat/lng lookup, ~36k places. GeoNames is preferred (it has population, so the biggest match wins for duplicate names); kelvins fills in very small places. Rows record both sources' coordinates and how far apart they are. |
| `geocoded_places.csv` | Generated by `manage.py geocode_stations` | One row per city/state pair in the fuel CSV with coordinates and their source (`geonames`, `kelvins` or `nominatim`). Places where the two table sources disagree by more than 5 miles were settled by Nominatim (majority of three). Committed so reviewers never need to geocode. |
| `usa_boundary.geojson` | [Natural Earth](https://www.naturalearthdata.com/) 1:10m admin-0 countries, public domain | The USA polygon (50 states, 36k vertices). Used with a ~1 km tolerance to reject start/finish inputs that resolve outside the country. |

Geocoding precision is at city level. Station addresses in the source file are interstate exits
("I-44, EXIT 283 & US-69") rather than street addresses, so a city centroid is the best available
anchor. The route corridor tolerance absorbs the few miles of error this introduces.

## Coverage of the price list

The supplied OPIS file covers truck stops unevenly. A few states have very few stations, so
some routes cannot be planned with a 500 mile range and the API says so (HTTP 422,
`planning_error`). Station counts after cleaning:

| State | Stations | Note |
|---|---|---|
| CA | 8 | all in the Imperial Valley; no coverage of I-5, LA or the Bay Area |
| AK, HI | 0 | not covered |
| OR | 29 | thin |
| TX, IL, MI, GA | 790 / 774 / 327 / 311 | dense |

So Los Angeles → San Francisco has no usable station at all, and a route down I-5 from
Seattle reaches its first station ~550 miles in. Coast-to-coast routes that cross the
southern states plan fine.
